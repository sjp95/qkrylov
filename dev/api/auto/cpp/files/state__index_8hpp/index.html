    Detailed Description

    Section titled “Detailed Description”

    Device-side state -> index lookup for sorted basis state lists.

    Three modes, chosen and verified at build time:

    • Identity: the basis is {0, 1, …, dim-1} (full spin-1/2 space). index = state, no tables.
    • Lin: H.Q. Lin’s two-table scheme. A state splits into high/low bit halves and index = hi_off[high] + lo_rank[low] – two cache-resident reads, no search. Valid when, for each high part, the matching low parts are exactly all lows of one “class” (same popcounts under the basis’ conserved masks). This is checked exactly against the state list; otherwise we fall back to:
    • Bisect: a prefix table over the top bits gives a short window, then binary search.
