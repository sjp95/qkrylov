Building the Hamiltonian¶

              

Welcome to the quickstart. In this tutorial, we will construct a 1D Heisenberg Spin-½ chain.

Step 1: The Hilbert Space¶

First, we define our Hilbert space. We use SpinHalfBasis.

import qkrylov as qk

b = qk.SpinHalfBasis(10, sz=0)
print(f"Basis dimension: {b.dimension}")

basis::SpinHalf b(10, sector::Sz(0));
    std::cout << "Basis dimension: " << b.dimension() << "\n";

using QuantumKrylov

b = SpinHalfBasis(10, Sector(0))
println("Basis dimension: ", dimension(b))

Step 2: Operator Sum¶

Next, we use OpSum to symbolically build our interactions.

ops = qk.OpSum()
J = 1.0
for i in range(9):
    ops += (J, "Sz", i, "Sz", i + 1)
    ops += (J*0.5, "Sp", i, "Sm", i + 1)
    ops += (J*0.5, "Sm", i, "Sp", i + 1)

OpSum ops;
    double J = 1.0;
    for (int i = 0; i < 9; ++i) {
        ops.add_term(OperatorTerm(J, {{"Sz", i}, {"Sz", i + 1}}));
        ops.add_term(OperatorTerm(J*0.5, {{"Sp", i}, {"Sm", i + 1}}));
        ops.add_term(OperatorTerm(J*0.5, {{"Sm", i}, {"Sp", i + 1}}));
    }

ops = OpSum()
J = 1.0
for i in 0:8
    add_term!(ops, J, "Sz", i, "Sz", i + 1)
    add_term!(ops, J*0.5, "Sp", i, "Sm", i + 1)
    add_term!(ops, J*0.5, "Sm", i, "Sp", i + 1)
end

Step 3: Solve¶

Finally, we construct the matrix-free Hamiltonian and solve it.

H = qk.MatrixFreeHamiltonian(b, ops, device="cpu")
result = qk.lanczos_ground_state(H)
print(f"Ground State Energy: {result.energy}")

# Output:
# Ground State Energy: -8.90438
